# Contributing

## Golden rules

1. **Never commit an NVIDIA `.run` or any extracted driver binary.** CI rejects it.
2. **Edit `common/`, not `packaging/`.** `packaging/**/debian/` is generated by
   `scripts/regen.sh`; hand edits are overwritten.
3. Every patch needs a `PROVENANCE.toml` entry before it can merge.
4. A new kernel/target never lands as `blocking: true` until one green run exists.

## Adding a compatibility patch

```sh
common/scripts/import-patches.sh 390xx --source meowice   # stages into patches/390xx/_incoming/
# pick the patch, rename with its gate:  0007-kernel-6.12-foo.patch.kmax-6.12
mv patches/390xx/_incoming/... common/patches/390xx/kernel/
$EDITOR common/patches/390xx/PROVENANCE.toml               # add [[patch]] block
common/scripts/import-patches.sh --check 390xx
```
Then in this repo: `make regen && make test SERIES=390xx TARGET=debian13`.

## Adding a driver series

1. `common/drivers.yaml`: add the `series:` block; `verify-run.sh --update <s>`.
2. `common/debian-template/<series>/` — copy the closest existing template, adjust
   the binary package set, EGL/Vulkan/NVENC flags, `xorg_abi_max`.
3. `common/patches/<series>/` + `PROVENANCE.toml`.
4. This repo: add to `series.yaml` (start `blocking: false`), `make regen`.
5. Open a PR; the full matrix runs.

## Adding a distro target

`common/drivers.yaml` `targets:` + OBS `_obs/project-meta.xml` repository +
`tests/dkms-matrix/kernels.yaml`. Keep it `blocking: false` in `series.yaml`
until proven.

## Local dev loop

```sh
make submodule
make regen
make lint
make build test SERIES=390xx TARGET=debian13
```

## DCO

Sign off commits (`git commit -s`). By doing so you assert you may contribute the
patch under this repo's MIT license (packaging) and that any imported third-party
patch is compatibly licensed and attributed in `PROVENANCE.toml`.
